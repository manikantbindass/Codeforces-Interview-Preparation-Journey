# 🇨🇳 Codeforces 面试准备之旅

## 📖 关于本项目

一个结构化的竞赛编程练习仓库，专注于 **Codeforces** 题目，旨在帮助你通过 **MAANG/FAANG** 级别的编程面试。题目按难度组织（简单 → 中等 → 困难），配有详细解释和多语言解决方案。

## 🎯 目标

- 使用 Codeforces 建立每日刷题习惯
- 掌握 MAANG 面试中测试的 15+ 种算法模式
- 从 rating 800 系统性地进阶到 2400+
- 创建一个文档完善的解决方案作品集

## 📂 如何使用本仓库

1. **从简单题目开始**，在 `problems/easy/` 中
2. **先阅读解题思路**，再看代码
3. **先自己尝试解决** 30-45 分钟
4. **对比你的解法** 与提供的解法
5. **记录你的进度** 在 `progress/tracker.md` 中
6. **使用自动化脚本** 创建新的题目文件

## 📁 文件夹结构

| 文件夹 | 用途 |
|--------|------|
| `problems/` | 按难度组织的所有已解决题目 |
| `templates/` | 题目文件和解决方案的模板 |
| `languages/` | 多语言 README |
| `scripts/` | 文件生成和统计的自动化脚本 |
| `progress/` | 进度跟踪和每日日志 |
| `assets/` | 图片、动画和图表 |
| `resources/` | 面试技巧和模式指南 |

## 🤝 如何贡献

1. Fork 本仓库
2. 创建分支：`git checkout -b add/problem-name`
3. 使用 `templates/problem_template.md` 中的模板添加你的解法
4. 遵循提交规范：`feat(easy): add 题目名称`
5. 发起 Pull Request
