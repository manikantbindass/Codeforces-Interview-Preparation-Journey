# 🇬🇧 Codeforces Interview Preparation Journey

## 📖 About This Project

A structured competitive programming practice repository focused on **Codeforces** problems, designed to help you crack **MAANG/FAANG-level** coding interviews. Problems are organized by difficulty (Easy → Medium → Hard) with detailed explanations and multi-language solutions.

## 🎯 Goal

- Build a daily problem-solving habit using Codeforces
- Master 15+ algorithmic patterns tested in MAANG interviews
- Progress from rating 800 → 2400+ systematically
- Create a portfolio of well-documented solutions

## 📂 How to Use This Repository

1. **Start with Easy problems** in `problems/easy/`
2. **Read the approach** before looking at the code
3. **Try solving yourself** for 30-45 minutes first
4. **Compare your solution** with the provided one
5. **Log your progress** in `progress/tracker.md`
6. **Use automation scripts** to create new problem files

## 📁 Folder Structure

| Folder | Purpose |
|--------|---------|
| `problems/` | All solved problems organized by difficulty |
| `templates/` | Templates for new problem files and solutions |
| `languages/` | README in multiple languages |
| `scripts/` | Automation scripts for file generation and stats |
| `progress/` | Progress tracking and daily logs |
| `assets/` | Images, animations, and graphs |
| `resources/` | Interview tips and pattern guides |

## 🤝 How to Contribute

1. Fork the repository
2. Create a branch: `git checkout -b add/problem-name`
3. Add your solution using the template in `templates/problem_template.md`
4. Follow the commit convention: `feat(easy): add Problem Name`
5. Open a Pull Request
