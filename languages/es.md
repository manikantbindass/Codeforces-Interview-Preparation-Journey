# 🇪🇸 Viaje de Preparación para Entrevistas con Codeforces

## 📖 Acerca de Este Proyecto

Un repositorio estructurado de práctica de programación competitiva enfocado en problemas de **Codeforces**, diseñado para ayudarte a superar entrevistas de codificación de nivel **MAANG/FAANG**. Los problemas están organizados por dificultad (Fácil → Medio → Difícil) con explicaciones detalladas y soluciones en múltiples lenguajes.

## 🎯 Objetivo

- Construir un hábito diario de resolución de problemas usando Codeforces
- Dominar más de 15 patrones algorítmicos evaluados en entrevistas MAANG
- Progresar del rating 800 → 2400+ de forma sistemática
- Crear un portafolio de soluciones bien documentadas

## 📂 Cómo Usar Este Repositorio

1. **Comienza con problemas Fáciles** en `problems/easy/`
2. **Lee el enfoque** antes de ver el código
3. **Intenta resolver por tu cuenta** durante 30-45 minutos primero
4. **Compara tu solución** con la proporcionada
5. **Registra tu progreso** en `progress/tracker.md`
6. **Usa los scripts de automatización** para crear nuevos archivos de problemas

## 📁 Estructura de Carpetas

| Carpeta | Propósito |
|---------|-----------|
| `problems/` | Todos los problemas resueltos organizados por dificultad |
| `templates/` | Plantillas para archivos de problemas y soluciones |
| `languages/` | README en múltiples idiomas |
| `scripts/` | Scripts de automatización para generación y estadísticas |
| `progress/` | Seguimiento de progreso y registros diarios |
| `assets/` | Imágenes, animaciones y gráficos |
| `resources/` | Consejos de entrevistas y guías de patrones |

## 🤝 Cómo Contribuir

1. Haz fork del repositorio
2. Crea una rama: `git checkout -b add/nombre-del-problema`
3. Agrega tu solución usando la plantilla en `templates/problem_template.md`
4. Sigue la convención de commits: `feat(easy): add Nombre del Problema`
5. Abre un Pull Request
