# 🇫🇷 Parcours de Préparation aux Entretiens Codeforces

## 📖 À Propos de Ce Projet

Un dépôt structuré de pratique de programmation compétitive axé sur les problèmes **Codeforces**, conçu pour vous aider à réussir les entretiens de codage de niveau **MAANG/FAANG**. Les problèmes sont organisés par difficulté (Facile → Moyen → Difficile) avec des explications détaillées et des solutions multi-langages.

## 🎯 Objectif

- Développer une habitude quotidienne de résolution de problèmes avec Codeforces
- Maîtriser plus de 15 modèles algorithmiques testés lors des entretiens MAANG
- Progresser du rating 800 → 2400+ de manière systématique
- Créer un portfolio de solutions bien documentées

## 📂 Comment Utiliser Ce Dépôt

1. **Commencez par les problèmes Faciles** dans `problems/easy/`
2. **Lisez l'approche** avant de regarder le code
3. **Essayez de résoudre vous-même** pendant 30-45 minutes d'abord
4. **Comparez votre solution** avec celle fournie
5. **Enregistrez vos progrès** dans `progress/tracker.md`
6. **Utilisez les scripts d'automatisation** pour créer de nouveaux fichiers

## 📁 Structure des Dossiers

| Dossier | Objectif |
|---------|----------|
| `problems/` | Tous les problèmes résolus organisés par difficulté |
| `templates/` | Modèles pour les fichiers de problèmes et solutions |
| `languages/` | README en plusieurs langues |
| `scripts/` | Scripts d'automatisation pour la génération et les statistiques |
| `progress/` | Suivi des progrès et journaux quotidiens |
| `assets/` | Images, animations et graphiques |
| `resources/` | Conseils d'entretien et guides de modèles |

## 🤝 Comment Contribuer

1. Forkez le dépôt
2. Créez une branche : `git checkout -b add/nom-du-probleme`
3. Ajoutez votre solution en utilisant le modèle dans `templates/problem_template.md`
4. Suivez la convention de commit : `feat(easy): add Nom du Problème`
5. Ouvrez une Pull Request
