# 🇮🇳 Codeforces நேர்காணல் தயாரிப்பு பயணம்

## 📖 இந்த திட்டத்தைப் பற்றி

**Codeforces** சிக்கல்களை மையமாகக் கொண்ட ஒரு கட்டமைக்கப்பட்ட போட்டி நிரலாக்க பயிற்சி களஞ்சியம், **MAANG/FAANG** நிலை குறியீட்டு நேர்காணல்களை வெற்றிகரமாக எதிர்கொள்ள உதவுவதற்காக வடிவமைக்கப்பட்டது. சிக்கல்கள் கடினத்தன்மை அடிப்படையில் ஒழுங்கமைக்கப்பட்டுள்ளன (எளிது → நடுத்தரம் → கடினம்) விரிவான விளக்கங்கள் மற்றும் பல மொழி தீர்வுகளுடன்.

## 🎯 இலக்கு

- Codeforces பயன்படுத்தி தினசரி சிக்கல் தீர்க்கும் பழக்கத்தை உருவாக்குதல்
- MAANG நேர்காணல்களில் சோதிக்கப்படும் 15+ அல்காரிதம் வடிவங்களை மாஸ்டர் செய்தல்
- மதிப்பீடு 800 → 2400+ வரை முறையாக முன்னேறுதல்
- நன்கு ஆவணப்படுத்தப்பட்ட தீர்வுகளின் போர்ட்ஃபோலியோவை உருவாக்குதல்

## 📂 இந்த களஞ்சியத்தை எவ்வாறு பயன்படுத்துவது

1. **எளிய சிக்கல்களில் தொடங்குங்கள்** `problems/easy/` இல்
2. **குறியீட்டைப் பார்ப்பதற்கு முன் அணுகுமுறையைப் படியுங்கள்**
3. **முதலில் 30-45 நிமிடங்கள் நீங்களே தீர்க்க முயற்சிக்கவும்**
4. **உங்கள் தீர்வை** வழங்கப்பட்டதுடன் ஒப்பிடுங்கள்
5. **உங்கள் முன்னேற்றத்தை பதிவு செய்யுங்கள்** `progress/tracker.md` இல்
6. **புதிய சிக்கல் கோப்புகளை உருவாக்க ஆட்டோமேஷன் ஸ்கிரிப்ட்களை பயன்படுத்தவும்**

## 📁 கோப்புறை கட்டமைப்பு

| கோப்புறை | நோக்கம் |
|----------|---------|
| `problems/` | கடினத்தன்மை அடிப்படையில் ஒழுங்கமைக்கப்பட்ட அனைத்து தீர்க்கப்பட்ட சிக்கல்கள் |
| `templates/` | சிக்கல் கோப்புகள் மற்றும் தீர்வுகளுக்கான வார்ப்புருக்கள் |
| `languages/` | பல மொழிகளில் README |
| `scripts/` | கோப்பு உருவாக்கம் மற்றும் புள்ளிவிவரங்களுக்கான ஆட்டோமேஷன் ஸ்கிரிப்ட்கள் |
| `progress/` | முன்னேற்ற கண்காணிப்பு மற்றும் தினசரி பதிவுகள் |
| `assets/` | படங்கள், அனிமேஷன்கள் மற்றும் வரைபடங்கள் |
| `resources/` | நேர்காணல் உதவிக்குறிப்புகள் மற்றும் வடிவ வழிகாட்டிகள் |

## 🤝 எவ்வாறு பங்களிப்பது

1. களஞ்சியத்தை Fork செய்யுங்கள்
2. ஒரு கிளையை உருவாக்குங்கள்: `git checkout -b add/problem-name`
3. `templates/problem_template.md` இல் உள்ள வார்ப்புருவைப் பயன்படுத்தி உங்கள் தீர்வைச் சேர்க்கவும்
4. கமிட் மரபை பின்பற்றுங்கள்: `feat(easy): add Problem Name`
5. ஒரு Pull Request திறக்கவும்
