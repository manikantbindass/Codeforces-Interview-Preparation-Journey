# 🇯🇵 Codeforces 面接準備ジャーニー

## 📖 このプロジェクトについて

**Codeforces** の問題に焦点を当てた構造化された競技プログラミング練習リポジトリです。**MAANG/FAANG** レベルのコーディング面接を突破するために設計されました。問題は難易度別（簡単 → 中級 → 難しい）に整理され、詳細な解説と多言語ソリューションが含まれています。

## 🎯 目標

- Codeforces を使って毎日の問題解決習慣を構築する
- MAANG 面接でテストされる 15 以上のアルゴリズムパターンをマスターする
- レーティング 800 → 2400+ まで体系的に上達する
- 十分にドキュメント化されたソリューションのポートフォリオを作成する

## 📂 このリポジトリの使い方

1. **簡単な問題から始める** `problems/easy/` にて
2. **コードを見る前にアプローチを読む**
3. **まず自分で 30-45 分間解いてみる**
4. **自分の解法を** 提供されたものと比較する
5. **進捗を記録する** `progress/tracker.md` にて
6. **自動化スクリプトを使って** 新しい問題ファイルを作成する

## 📁 フォルダ構造

| フォルダ | 目的 |
|----------|------|
| `problems/` | 難易度別に整理された解決済みの全問題 |
| `templates/` | 問題ファイルとソリューションのテンプレート |
| `languages/` | 多言語の README |
| `scripts/` | ファイル生成と統計の自動化スクリプト |
| `progress/` | 進捗追跡と日次ログ |
| `assets/` | 画像、アニメーション、グラフ |
| `resources/` | 面接のヒントとパターンガイド |

## 🤝 貢献方法

1. リポジトリをフォークする
2. ブランチを作成：`git checkout -b add/problem-name`
3. `templates/problem_template.md` のテンプレートを使ってソリューションを追加
4. コミット規約に従う：`feat(easy): add 問題名`
5. プルリクエストを開く
