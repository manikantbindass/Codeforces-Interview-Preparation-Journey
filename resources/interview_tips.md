# 💡 MAANG/FAANG Interview Tips

## 📋 Before the Interview

### Technical Preparation
- Solve 150+ problems covering all major patterns
- Practice on a whiteboard or shared document (no IDE autocomplete)
- Time yourself: 20 min easy, 35 min medium, 45 min hard
- Review solutions the next day — spaced repetition works

### Behavioral Preparation
- Prepare 5-7 STAR stories (Situation, Task, Action, Result)
- Research company values and map your stories to them
- Practice explaining technical decisions to non-technical people

---

## 🎯 During the Interview

### The Communication Framework

```
1. ASK     → Clarify constraints, edge cases, input size
2. PLAN    → Explain your approach, get confirmation
3. CODE    → Write clean, modular code
4. TEST    → Walk through with examples
5. DISCUSS → Time/space complexity, trade-offs
```

### Common Mistakes to Avoid

| ❌ Don't | ✅ Do |
|----------|-------|
| Jump straight to coding | Discuss approach first |
| Stay silent while thinking | Think out loud |
| Write messy variable names | Use descriptive names |
| Ignore edge cases | Explicitly handle them |
| Give up on hard problems | Discuss partial solutions |
| Memorize solutions | Understand patterns |

## 🏢 Company-Specific Notes

### Google
- Heavy on algorithms and data structures
- System design for senior roles
- "Googliness" behavioral assessment
- Multiple rounds (4-5 interviews)

### Meta (Facebook)
- Two coding rounds + system design + behavioral
- Focus on optimal solutions
- Ninja and Jedi behavioral values

### Amazon
- Leadership Principles are CRITICAL
- Always have STAR stories ready
- Online assessment → phone screen → on-site loop
- Working backwards from customer needs

### Apple
- Team-specific interviews
- Deep dive into past projects
- Emphasis on design and user experience

### Microsoft
- 4-5 rounds including "As appropriate" with hiring manager
- Problem-solving and design thinking
- Collaborative coding approach

## 🧠 Mental Framework

> "I don't know the answer yet, but here's how I'm thinking about it..."

This single phrase transforms an interview from a test into a collaboration. Always share your thought process.
