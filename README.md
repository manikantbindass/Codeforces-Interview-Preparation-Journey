## 🚀 Introduction

Welcome to **Codeforces Interview Preparation Journey** — a structured, daily competitive programming practice repository built to crack **MAANG/FAANG-level coding interviews**.

This repository follows a progressive difficulty curve: **Easy → Medium → Hard**, with detailed explanations, multi-language solutions, and automation scripts to keep you on track.

> 💡 *"The only way to get better at problem-solving is to solve problems every single day."*

## 🧠 Problem Solving Strategy

### The MAANG Framework

```
1. UNDERSTAND  →  Read problem 2-3 times. Identify constraints.
2. EXAMPLES    →  Work through examples by hand. Find edge cases.
3. PATTERN     →  Map to known algorithmic pattern.
4. PSEUDOCODE  →  Write approach before coding.
5. CODE        →  Implement clean solution.
6. TEST        →  Verify with examples + edge cases.
7. OPTIMIZE    →  Analyze complexity. Can you do better?
```

### 📋 Pattern Recognition Guide

| Pattern | When to Use | Example Problems |
|---------|-------------|-----------------|
| Two Pointers | Sorted arrays, pair finding | Two Sum (sorted) |
| Sliding Window | Contiguous subarray/substring | Max sum subarray |
| Binary Search | Sorted data, monotonic function | Search in rotated array |
| BFS/DFS | Graph traversal, shortest path | Number of islands |
| Dynamic Programming | Overlapping subproblems | Fibonacci, Knapsack |
| Greedy | Local optimal = global optimal | Activity selection |
| Union Find | Connected components | Network connectivity |
| Topological Sort | Dependency ordering | Course schedule |
| Trie | Prefix-based search | Autocomplete |
| Segment Tree | Range queries with updates | Range sum queries |

## 🤝 Contribution Guide

1. **Fork** the repository
2. **Create** a new branch: `git checkout -b add/problem-name`
3. **Add** your solution using the [problem template](templates/problem_template.md)
4. **Commit**: `git commit -m "feat(easy): add Watermelon solution"`
5. **Push**: `git push origin add/problem-name`
6. **PR**: Open a Pull Request with description

### Commit Convention

```
feat(easy):    New easy problem
feat(medium):  New medium problem
feat(hard):    New hard problem
fix:           Bug fix in solution
docs:          Documentation update
scripts:       Automation script changes
```

## 💡 Interview Tips

<details>
<summary>🏢 MAANG Interview Prep Checklist</summary>

- [ ] Master 150+ problems across all patterns
- [ ] Practice system design basics
- [ ] Mock interviews (2x/week minimum)
- [ ] Time yourself (45 min per problem max)
- [ ] Explain approach out loud while coding
- [ ] Review and revisit problems after 1 week
- [ ] Focus on patterns, not memorization

</details>

<details>
<summary>⏱️ Time Management During Interviews</summary>

| Phase | Time | Action |
|-------|------|--------|
| Understand | 5 min | Clarify requirements, ask questions |
| Plan | 5-10 min | Discuss approach, get buy-in |
| Code | 15-20 min | Write clean, modular code |
| Test | 5-10 min | Walk through examples, edge cases |
| Optimize | 5 min | Discuss trade-offs, improvements |

</details>
